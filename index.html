GET STARTED

Setup Guide

Get a server ready for its first QOTD in a few steps.

01

Invite QOTD Bot

Use the Add to Discord button and select the server where you want to use QOTD Bot.

02

Run /setup

Configure the QOTD channel, role and language for the server.

03

Check /config

Confirm that the saved settings match the server configuration.

04

Create your first QOTD

Run /qotd and start the discussion thread.

Frequently Asked Questions

Why isn't /qotd working?

Check that the bot is configured with /setup, that the selected channel and role are correct, and that the server permissions allow the command.

How do I change the QOTD channel?

Run /setup again and update the server's QOTD configuration.

What does /lock do?

It lets an authorized owner temporarily prevent new QOTDs from being created.

What is /audit_log?

It provides a separate, detailed record of bot interaction attempts and errors for the server. It is restricted to the Bot Owner or Server Owner.

Can I use QOTD Bot on multiple servers?

Yes. Each server has its own configuration, counters, QOTD history and normal logs.
