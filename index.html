COMMAND DETAILS

How the commands work

Open a command below to see what it does, what it expects, and who can use it.

/qotd

Creates a new QOTD using the configured server settings. The command supports a question, language, an optional channel, and an optional suggested-by member. Access uses the configured allowed role, with Bot Owner and Server Owner access also supported.

/edit

Edits an existing QOTD by its Discord message ID. You provide the message ID and the new question. Access uses the configured allowed role, Bot Owner, or Server Owner.

/delete

Deletes an existing QOTD by Discord message ID. Access uses the configured allowed role, Bot Owner, or Server Owner.

/info

Shows information about a QOTD identified by Discord message ID. Restricted to the Bot Owner or Server Owner.

/stats

Shows QOTD statistics for the current server. It is not a global statistics command.

/leaderboard

Shows two QOTD rankings for the current server: creators and responders, with All / English / Russian language filtering.

/history

Shows the QOTD history for the current server.

/setup

Configures the QOTD mention role, allowed role, optional English and Russian channels, and the bot language. Restricted to the Bot Owner or Server Owner.

/config

Displays the current QOTD configuration for the server. Restricted to the Bot Owner or Server Owner.

/logs

Displays and filters normal QOTD logs with pagination and Refresh controls. Restricted to the Bot Owner or Server Owner.

/audit_log

Displays the separate interaction audit log, including interaction attempts and errors. Restricted to the Bot Owner or Server Owner and designed not to store secrets.

/reset_logs

Clears the normal QOTD logs. Restricted to the Bot Owner or Server Owner.

/reset

Resets the QOTD counter for the server. Restricted to the Bot Owner or Server Owner.

/maintenance

Turns QOTD maintenance mode on or off. While enabled, QOTD creation is blocked. Restricted to the Bot Owner or Server Owner.

/lock

Locks or unlocks QOTD creation for the server. Restricted to the Bot Owner or Server Owner.

/help

Shows the bot's available commands and help categories.

Frequently Asked Questions

Why isn't /qotd working?

Check that the bot is configured with /setup, that the selected roles and channels are correct, and that the user has the configured allowed role.

How do I change the QOTD channel?

Run /setup again and update the English and/or Russian QOTD channel. You can also choose a channel directly when using /qotd.

What does /lock do?

It lets an authorized owner temporarily prevent new QOTDs from being created.

What is /audit_log?

It provides a separate, detailed record of bot interaction attempts and errors for the server. It is restricted to the Bot Owner or Server Owner.

Can I use Quello on multiple servers?

Yes. Each server has its own configuration, counters, QOTD history and normal logs.

TROUBLESHOOTING

Something not working?

Use these quick checks before changing your server configuration.

/qotd is unavailable

Run /setup and verify the allowed role, QOTD channels, and language. Make sure the user has the configured allowed role.

The bot cannot send the QOTD

Check that Quello can view the target channel, send messages, mention the configured role, and create threads there.

The QOTD counter is unexpected

Check the server counter with the relevant management commands. Remember that failed operations can leave number gaps because counters are kept safe for concurrent use.

I need to stop new QOTDs temporarily

Use /lock for a temporary lock or /maintenance when the server is being serviced.

I need to inspect bot interactions

Use /logs for normal QOTD activity or /audit_log for the separate interaction audit record.
