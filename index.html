QOTD Bot

A Discord bot for creating, managing, and tracking Question of the Day posts, server statistics, logs, and administrative settings.

Add to Discord Join our Discord Terms of Service Privacy Policy

Questions of the Day

Create QOTDs with language-specific channels, numbering, role mentions, optional suggestions, and automatic Discord threads. Authorized users can edit or delete existing QOTDs.

History & Statistics

View server-only QOTD statistics, contributor leaderboards, and QOTD history with language filters.

Logs & Administration

Configure the bot, review QOTD logs, use the detailed audit log, reset counters or logs, and control maintenance and QOTD lock modes.

Commands

The current QOTD Bot command set.

QOTD

  • /qotd — Create a new Question of the Day.
  • /edit — Edit a QOTD by Discord message ID.
  • /delete — Delete a QOTD by Discord message ID.
  • /info — View information about a QOTD by Discord message ID.

Statistics

  • /stats — View QOTD statistics for the current server.
  • /leaderboard — View the QOTD contributor leaderboard.
  • /history — View QOTD history.

Configuration

  • /setup — Configure QOTD roles, channels, and bot language.
  • /config — View the current QOTD configuration.

Logs

  • /logs — View and filter QOTD bot logs.
  • /audit_log — View detailed interaction attempts and errors for the server.
  • /reset_logs — Delete the normal QOTD logs for the server.

Server Management

  • /reset — Reset the QOTD counter.
  • /maintenance — Enable or disable QOTD maintenance mode.
  • /lock — Lock or unlock QOTD creation.

Other

  • /help — Show the available QOTD Bot commands.

Permissions: /qotd, /edit, and /delete use the configured QOTD role permissions. Administrative commands and logs are restricted to the Bot Owner or Server Owner where applicable.

Administration & Safety

Maintenance modeTemporarily prevents QOTD creation while the server is being maintained.
QOTD lockAllows authorized owners to lock QOTD creation independently of maintenance mode.
Audit logTracks interaction attempts and command errors for the server without storing command arguments or secrets.
Async databaseThe bot uses aiosqlite for its application database operations.
